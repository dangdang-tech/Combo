# Creator Worker 构建工具

`build-receiver.mjs` 使用开发依赖中固定的 Bun 1.4.2，将编译后的接收器入口构建为四个 macOS/Linux、x64/arm64 二进制。它关闭所有项目配置自动加载，清理构建进程启动覆盖变量，核对体积，按完整文件摘要命名，并生成严格的分发清单。缓存位于工作区依赖目录或调用者明确指定的数据盘目录。API 构建复用这些产物，服务进程不执行 Bun。

运行环境、二进制、生成清单均不提交 Git。打包不等同于 macOS Developer ID 签名或公证；后续签名改变文件字节时，发布流程必须重新计算并绑定最终产物摘要。
