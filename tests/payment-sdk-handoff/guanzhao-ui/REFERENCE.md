## 本次设计采用的部分

观照借鉴了先查看余额、再选择套餐、进入托管收银台、返回确认并刷新余额的顺序，同时补充发送按钮成本、保留原问题、结果未知继续核实原订单和过期分支。颜色、字体、布局和文案延续观照自己的纸本与墨夜主题。

观照原型仍使用 100 点 / ¥10、320 点 / ¥30、800 点 / ¥68 的演示配置，不把 ChatGua 的美元套餐移作观照正式价格。真实支付能力与账务由 Combo #357 对应后端增量负责。参考元数据见 `evidence/chatgua-public-reference.json`。
